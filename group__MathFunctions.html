◆ d_isFinite() [1/2]

bool d_isFinite ( const double value)
inlinestaticnoexcept

Check if a floating point number is finite, that is neither infinite nor NaN.

Use this instead of std::isfinite, std::isnan or std::isinf on values from outside your own code, such as parameter values from the host. DAF's Makefile builds compile with -ffast-math, which lets the compiler assume that no value is ever infinite or NaN, and GCC and Clang then fold those checks to a constant: the check is silently compiled out. This reads the bit pattern instead, through a volatile, so neither compiler can apply that assumption to it.
